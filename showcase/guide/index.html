Deploy this yourself.

Three static sites, zero build step, no dependencies. Any static host serves the showcase/ folder unmodified. Two proven paths below — the fast one and the sovereign one.

What you're deploying

showcase/
├── index.html            landing page — the triptych
├── terminal/index.html   Site 1 · The Sovereign Logic Terminal
├── dungeon/index.html    Site 2 · Dungeon of Agreements
├── matrix/index.html     Site 3 · The Discrepancy Matrix
├── guide/index.html      this page, at /guide
└── netlify.toml          Netlify config (headers only — no build)

Preview locally first:

cd showcase
python3 -m http.server 8080   # → http://localhost:8080

Option A — Netlify

A1 · DRAG & DROP

Open app.netlify.com/drop, drag the showcase/ folder in, get a live URL in ~10 seconds. Rename it under Site settings.

A2 · CLI

For repeatable deploys from the terminal — see below.

npm install -g netlify-cli
netlify login                    # browser OAuth
cd showcase
netlify deploy --dir=. --prod    # prints the live URL

Continuous deploys from Git

  1. Netlify dashboard → Add new site → Import an existing project
  2. Select this repository · Base directory: showcase · build command empty · Publish directory: showcase
  3. Every push redeploys automatically.

Custom domain

Domain management → Add a domain → follow the DNS steps (Netlify DNS or a CNAME/A record at your registrar). Let's Encrypt HTTPS is automatic.

Option B — Hostinger VPS · one domain per site

Full control: map bullshitdecoder.com → the Terminal and theeggplantfiles.com → the Matrix (or serve the whole triptych from one domain — the sites cross-link with relative paths, so the landing page works best at the root).

1 · Upload

rsync -avz showcase/ user@YOUR-VPS-IP:/var/www/triptych/

2 · nginx server block per domain

# /etc/nginx/sites-available/bullshitdecoder.com
server {
    listen 80;
    server_name bullshitdecoder.com www.bullshitdecoder.com;
    root /var/www/triptych/terminal;      # or /var/www/triptych for the full triptych
    index index.html;
    location / { try_files $uri $uri/ =404; }
}
sudo ln -s /etc/nginx/sites-available/bullshitdecoder.com /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

3 · DNS

In Hostinger's DNS panel: A record for @ and www → your VPS IP.

4 · Free HTTPS

sudo apt install certbot python3-certbot-nginx
sudo certbot --nginx -d bullshitdecoder.com -d www.bullshitdecoder.com

Sanity checklist

  • Local preview looks right
  • / · /terminal/ · /dungeon/ · /matrix/ · /guide/ all load on the live URL
  • HTTPS padlock present
  • Each site's devtools console prints its build iteration log — quick script-integrity check
